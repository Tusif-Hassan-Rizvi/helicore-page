# Ada Psychiatry - Responsive Landing Page

A modern, responsive, and pixel-perfect healthcare landing page built for **Ada Psychiatry**, developed as a technical evaluation task for **Helicore Info Pvt Ltd**.

Live Demo: [https://ada-homepage-alpha.vercel.app/](https://ada-homepage-alpha.vercel.app/)  
GitHub Repository: [https://github.com/Tusif-Hassan-Rizvi/helicore-page](https://github.com/Tusif-Hassan-Rizvi/helicore-page)

---

## Tech Stack

- **Framework:** React 19 + TypeScript
- **Build Tool:** Vite 8
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`)
- **Carousel & Sliders:** Swiper.js (Autoplay, Custom Hexagonal SVG Pagination)
- **Scroll Animations:** AOS (Animate On Scroll)
- **Icons & Graphics:** Custom vector SVGs and optimized WebP/PNG assets

## Getting Started

### Prerequisites

- Node.js (version 18+ or 20+ recommended)
- npm or yarn or pnpm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Tusif-Hassan-Rizvi/helicore-page.git
cd helicore-page
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

5. Preview production build locally:
```bash
npm run preview
```
